# User Posts in a Topic Extension for phpBB 3.1

This extension users, if so authed to search, to be able to click on a link within a topic on a user and see all the posts from that user that are within the topic.

## Requirements
* phpBB 3.1.0-a2 or higher
* PHP 5.3.3 or higher

## Installation
1. Download the repository ZIP and unzip it.
2. Copy the entire contents from the unzipped folder to `phpBB/ext/rmcgirr83/userpostsinatopic/`.
3. Navigate in the ACP to `Customise -> Manage extensions`.
4. Find Poster IP in Viewtopic under "Disabled Extensions" and click `Enable`.

## Uninstallation
1. Navigate in the ACP to `Customise -> Manage extensions`.
2. Click the `Disable` link for Poster IP.
3. To permanently uninstall, click `Delete Data`, then delete the `userpostsinatopic` folder from `phpBB/ext/rmcgirr83/`.
